# 紫雾手账 · 底部导航选中态：手撕和纸胶带

日期：2026-10-20。只改 `LavenderScrapbook.kt` 的 `ScrapbookTabBar`，**原版主题零影响**。

## 做法

- **造型**：横向矩形 + 两端细密小三角锯齿（每侧约 10 个齿，齿距 2.6dp、齿深 2.4dp），锯齿向内凹，不超出这块区域、不压到旁边的入口。
- **覆盖关系**：拼贴图标在下，浅紫半透明胶带**盖在图标之上**（同一 `Box` 里后声明的子元素在上层）。
- **透明度**：`Color(0xFFA78FD0).copy(alpha = 0.28f)`，28%，落在要求的 20–30% 区间；图标细节透得出来。
- **取消阴影**：删掉了原来图标下面那块 `drawRoundRect` 圆角纸片；新选中态只有胶带这一层，没有投影、发光、底座。
- **文字**：选中标签用 `TapeInk`（0xFF3A2E4B）比常态的 `Ink`（0xFF40364F）略深一档，不加阴影。
- **未选中**：完全不动，没有胶带。
- **尺寸**：胶带 44×27dp，向上偏移 3dp，落在图标区域上方、不压白色波浪带。

## 实测（荣耀 YAL-AL50 / Android 10）

| 检查项 | 结果 |
|---|---|
| 锯齿 | 两端细密三角，可辨认（放大 3 倍截图确认） |
| 透明度 | 28%，图标透出清晰，胶带边界可见 |
| 图标清晰度 | 未受影响（未重绘、未缩放） |
| 阴影/发光/底座 | 无，已删除旧纸片 |
| 未选中 | 保持原样 |
| 主题隔离 | 改动只在 `ScrapbookTabBar`，原版玻璃导航未触及 |

## 迭代记录

1. v1：胶带 46×32、齿距 3.4dp、色 E5D9F1@26% —— 太接近米白，几乎看不见；且旧的圆角纸片还在，变成两层。
2. v2：删旧纸片，色改 B49ED6@26% —— 能看出胶带，但锯齿偏粗、胶带压住波浪带。
3. v3：放大 50×33、齿距 4.4 —— 锯齿明显了，但占位过大。
4. v4：44×30、齿距 2.6（细密） —— 接近目标，底边仍压波浪带。
5. v5（交付版）：44×27 + 上移 3dp，色 A78FD0@28% —— 锯齿细密、不压波浪带、图标清晰。
