# 紫雾手账 · 第一批交接与验收

基线：二改主开发分支 `feature/chat-file-upload-and-hold-to-talk` 的 `04d41b2bd779700c56d9d3592c1ea48461606478`，0.1.92-mod。工作分支：`feat/lavender-scrapbook-batch01`。只供独立分支复核，不自动合并或发布 APK。

## 已实现

- 新主题键 `mod_visual_theme`，值 `native_default` / `lavender_scrapbook`。空值、未知值解析为原版默认；不迁移、不复用既有玻璃、气泡、壁纸或启动器键。
- 设置 → 外观 → 界面主题：原版默认 / 紫雾手账·试用，原生可访问单选项。主动选择通过 DataStore 原子写入；启动已有的等待设置机制继续保留。
- 手账绘制在 CompositionLocal 中分派。默认仍执行既有玻璃节点与壁纸；手账模式不创建 LiquidGlassElement，使用独立纸面背景和原生无模糊表面。现有控件尺寸、点击回调、数据与导航路由不改。
- 四入口导航采用参考图第四排的细窄波浪连接带，约6dp厚，轻描边；局部淡紫纸片标记，不升高选中项。保留原4入口，未照搬设计稿中的7入口以免新增导航业务。图标暂用原生语义向量，拼贴图标正式接入留到后续批次；没有把整张参考图当作导航背景。
- 导航外框沿用92dp，以保持现有 bottomInset；MainScreen 原有键盘弹出隐藏导航的逻辑和页面切换代码未动。最小触摸高度56dp；标签为动态 Text，支持系统字体缩放；窄屏、大字体实际效果待测。
- 备份导出/恢复包含独立主题字段；旧备份缺少字段时恢复原版。升级未设置新字段的用户维持原玻璃/气泡/壁纸设置；后续升级继续读取已保存主题。
- 设置写入 IOException 时，本次进程强制回退原版并提示，成功重试解除回退；原子写入失败不会清除磁盘旧值。因此在磁盘无法写入时，不能保证重启后仍停留于回退值，重启会重新读取上次成功保存的主题。主题调色板初始化失败也退回原版。未实现任意 Compose 绘制异常的全局自动恢复。

## 原版隔离审计

原有 drawable/mipmap、Manifest、GlassStyle、GlassTheme 与 LiquidGlass 渲染节点实现不改。只在绘制入口增加主题分支；主题新增文件与资源命名独立。本分支基于主开发线，不合并之前默认开启纸绘替换的实验分支。Aster 首批图标及先前纸绘分支均保留。

后续若 DSH 合并 paper-functional-icons，必须将 PaperIcon 的替换行为纳入显式独立图标方案，原版默认下直接调用 Material Icon，不能只依赖默认开启的 BuildConfig 开关。否则原版恢复要求会被另一个分支破坏。水晶方案未在本基线中发现，未修改其资源或猜测其配置。
