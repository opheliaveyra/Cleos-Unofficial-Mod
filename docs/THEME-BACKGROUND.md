# 紫雾手账 · 固定主题背景接入

日期：2026-10-20。完整主题接入，不是「可自由选择的普通壁纸」。

## 一、背景

- 资源：`res/drawable-nodpi/scrap_bg_paper.png`，852×1846，**Aster 原图直用**，没有重绘、没有重新生成、没有压缩改色（原文件 2.6 MB 原样打包）。
- 渲染：`ScrapbookBackground()` 用 `Image + ContentScale.Crop`，等比放大填满，不拉伸不变形。
  852×1846 = 0.4615，正好是 1080×2340 等常见手机的比例，四角的装饰（花、丝带、照片）完整保留；
  比例偏差大的屏幕只在中缝裁掉极少一点。
- 覆盖：所有页面共用同一层背景（`CleosTheme` 里 `if (scrapbook) ScrapbookBackground()`），
  聊天、日记、待办、主页、设置、各二级页都走这一层。
- 可读性：内容卡片仍是暖白纸面，铺在背景之上；文字用深墨色，对比度没降。

## 二、主题配置锁定

- **整套生效**：背景图 + 拼贴图标 + 淡紫雾蓝暖白配色 + 纸感卡片/输入框 + 锯齿胶带选中态，一起切换。
- **主题内不能单独改背景**：外观页在 lavender 下把「换壁纸 / 用回默认」两个按钮整段换成一句说明，
  不提供入口（截图 07）。
- **不删除用户配置**：只是不显示入口、不应用；`settings.wallpaper` 一个字没动。
- **切走恢复**：切回「原版默认」后壁纸、玻璃、气泡全部照旧（截图 05），再切回来背景重新生效（截图 06）。
- **外观入口副标题**：lavender 下显示「紫雾手账 · 固定背景」，不再显示「自己的壁纸 · 玻璃跟随壁纸」。

## 三、保持现有设计

底部导航选中态**没动**：浅紫锯齿胶带 + 横向纸条 + 图标淡紫覆盖 + 无阴影 + 未选中原生纸绘，与定稿一致。

## 四、主题隔离

- 改动只在 `LavenderScrapbook.kt` 的 `ScrapbookBackground()`、`AppPages.kt` 的壁纸 Section 条件、
  `SettingsPages.kt` 的入口副标题。
- 原版默认主题的 `Wallpaper()` 一行未改；原版主题行为、资源、玻璃全部保持原样。

## 已知取舍

- 背景是固定图，不随系统深浅色变化（主题本身就是浅色一套）。
- 玻璃 Section 仍留在外观页：它控制的是原版玻璃参数，在 lavender 下不生效，但留着不影响视觉；
  如果要求「主题内不出现任何原版参数入口」，可以下一轮一起隐藏。
