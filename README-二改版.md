# Cleos 二改版（非官方）

> ⚠️ 这不是官方版本。我是用户，不是 Cleos 的作者，这个仓库和官方项目没有隶属关系。
> 官方项目：https://github.com/jqzhang921-sudo/cleos

基于官方 Cleos 源码（Apache-2.0）做的个人修改版，保留官方完整 Git 历史；
所有二改提交都在 `feature/chat-file-upload-and-hold-to-talk` 分支上，版本号按 `0.1.x-mod` 递增。
当前源码版本：`0.1.65-mod`（`app/build.gradle.kts`）。

## 已实现功能（相对官方）

### 模型与请求
- 三层模型结构：服务商 → 模型配置 → 功能绑定（单聊 / 群聊 / 看图 / 视频理解 / 摘要 / 记忆 / 日记 / 信件 / 工具等），统一解析入口
- 同一服务商复用地址与 Key；批量拉取模型、搜索、多选、手动添加；参数继承与覆盖顺序固定
- 能力声明 / 探测结果 / 未知三种状态分开；一次失败不直接判定"不支持"
- 视频理解：独立模型读视频 → 描述交给当前聊天模型；同视频同模型只解析一次；失败原因可见、可重试；视频气泡下有状态提示

### 聊天
- 单聊 / 群聊输入栏统一；「＋」面板换行网格、可滚动；按钮视觉统一（34dp 视觉 / 44dp 点击）
- 按住输入框说话（左滑转文字 / 右滑发语音 / 上滑取消），单聊群聊共用
- 聊天拍照（单聊 + 群聊，预览后可重拍 / 取消）
- 会话重命名（标题与角色名分开存，手动命名不被自动标题覆盖）
- 消息编辑、角色回复重试；生成中可以停止

### 群聊
- 群内语音、群里发图；TA 自主互聊
- 用量按发言角色记录

### 头像与主页
- 全局默认头像 + 每个角色 / 每个群单独的「我的头像」，优先级：角色/群专属 > 全局；主页「我与 TA」跟随当前角色
- 头像裁剪（拖动、缩放、圆形），角色设置里并排预览「我的头像 + 角色头像」

### 日记与记忆
- 日记页按角色（默认只看当前角色的那本）；「所有角色」是主动点进去的汇总视图；类型筛选独立一排
- 记忆、日记都按角色 ID 绑定，模型读取也隔离

### 备份与兼容
- 修了原版备份导入被误判「来自更新版本」的问题：格式版本不再按数字大小直接拒绝，先尝试导入并给出提示
- 导入前只读概览（TA / 对话 / 消息 / 日记 / 记忆 / 群聊数量），确认后才替换
- MCP 服务配置纳入备份

### 其它
- 外部服务（MCP）：手动 / 粘贴 JSON / 导入文件三种添加方式；多请求头；Streamable HTTP 与老式 SSE
- Token 用量统计（设置 › 用量统计）
- 一键反馈（版本 / 系统 / 页面 / 脱敏错误 + 描述 + 截图，复制或导出，不自动发送）
- 虚拟屏可行性探针（验证工具，见下）

## 最近版本（0.1.63 – 0.1.65）

- **0.1.63-mod**：PDF 上传修复。文字放在 Form XObject 里的 PDF 以前整页漏读；读不出时按真实原因

  气泡里最多 360dp，超了会写「内容较长，点开放大看全部」。
- **0.1.65-mod**：继续查 HTML 内容不全。单测确认「字符串 → 解析」不丢内容后，给固定高度 +
  `overflow: hidden` 的卡片加「溢出可见」兜底，并加诊断日志（`adb logcat -s CleosWidget`，可移除）。

## Windows 桌面客户端（测试中）

仓库里有独立的 `desktop/` 模块（Compose Multiplatform Desktop），和 Android 版两套代码、互不影响。
第一阶段只做：服务商/模型配置、角色、流式聊天与停止、本地保存与重启恢复；没有音频、附件、日记、记忆；
还不是安装包。构建：`gradlew :desktop:bundleRuntime`。

## 构建

- JDK 21
- Android SDK：compileSdk 37 / targetSdk 36 / minSdk 29
- 命令行：`./gradlew :app:assembleDebug`（Windows：`gradlew.bat :app:assembleDebug`）
- 产物：`app/build/outputs/apk/debug/app-debug.apk`
- 默认 debug 签名，仅供自用测试；要正式签名请自备 keystore（**不要提交到仓库**）

## 安装

- `adb install -r app-debug.apk`，或手机上直接覆盖安装
- **不要先卸载**：卸载会清掉聊天记录、日记等本地数据；升级前建议先在「数据与备份」导出一份

## 已知问题

- 「外观按角色独立」（每个角色一套壁纸 / 气泡 / 字体）**还没做**：目前外观是全局单份
- Token 用量统计只接了单聊 / 群聊 / 看图；总结、记忆、日记、信件、朋友圈、连接测试等后台请求**还没记录**；没有费用统计、导出、进备份
- 聊天记录搜索只支持当前角色，不能按角色 / 群切换，也没有搜索历史、群消息搜索
- 单聊文字草稿没有持久化（群聊有）；消息撤回、回复版本切换没做
- 群聊不能发视频
- 视频理解链路**未在真机上用真实视频验证过**
- 虚拟屏（让角色在独立屏里刷抖音）：普通未 root 手机**不可行**（把别的 App 启动到虚拟屏、往虚拟屏注入手势都需要系统权限）；目前只有探针，没有可用功能
