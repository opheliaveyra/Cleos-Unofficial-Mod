# Aster 纸绘资源 · batch01-r1

本批以原始 `cleos_paper_icons_batch01.zip` 的四枚独立 PNG 为依据，不重画、不替换此前 41 枚向量，不修改 App 源码。原 ZIP 与本次十张附件逐字节保存在 reference/，后续批次增量增加，禁止覆盖已交付 ZIP。

## 规范与目录

- png/: home、chat、diary、todo；512×512 RGBA，长边主体 416px，居中，至少 46px 安全留白。保留淡紫、雾蓝、暖白与原始纸绘轮廓，不增加底板。
- source/: 同名 SVG，内嵌高清透明位图并保留独立图层 ID；这是保留水彩的源容器，不是纯路径矢量。原始画面分辨率有限，512px 输出不意味着增加了原画细节。
- reference/: 原始 ZIP 和十张附件，保留设计依据。01 为 RGB 棋盘格展示稿，不作为透明资源；其他 RGBA 附件仅作为参考，不将透明通道存在视作边缘已合格。
- previews/: 16/24/32/48px 在白色、深色、灰紫背景上的缩放检查。
- icon-manifest.csv: 名称、功能、PNG/源文件路径、现有使用位置、接入状态。
- TEST_REPORT.json: 原始/输出哈希、包围盒、清除像素数量及透明通道数据。

## 本批修改与验证

清除孤立 alpha 杂点，特别是 diary 左侧与书本无关的残线；清除近透明 RGB 残色；统一主体长边与留白。保留主体内半透明水彩，不全局按颜色抠除暖白，也不强行填满 alpha。工具为 tools/paper-aster/refine_batch01.py，依赖 Pillow、NumPy、SciPy；无 App 新依赖。

已检查四枚均为 512×512 RGBA，边界透明，无文字标签或棋盘格底板；逐枚检查三种背景与四种尺寸。24–48px 主体可辨，16px 细节明显损失，不建议用作16dp通用操作图标。缩放图是静态资源检查，不是 Android 页面截图。未进行 APK 构建、真机对比度/点击检查或实际页面截图，待 DSH 接入验收。

## DSH 接入说明

本批仅交付资源，未自动切换已有 PaperIcon 映射。接入时将四枚 PNG 放入 drawable-nodpi，以 Image(painterResource(...), contentDescription=原描述) 绘制，不使用单色 tint；保持现有 Modifier、点击、导航、选中态和玻璃底栏。当前导航定义在 ui/MainScreen.kt 的 GlassTab 列表中，聊天/日记/待办/主页依次对应 chat/diary/todo/home。先在独立开关下接入，与旧向量切换对照；不改启动器的16个可选图标。
